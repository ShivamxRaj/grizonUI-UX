## Brand & Style

The design system embodies a serene, sovereign, and deeply intelligent aesthetic tailored for an enterprise-grade multi-agent AI ecosystem. Rooted in modern Indian technical excellence, it balances cutting-edge autonomous capability with contemplative calm and quiet authority. The visual atmosphere moves away from aggressive hyper-tech aesthetics toward an ethereal, warm-light clarity reminiscent of refined editorial publishing paired with ambient intelligence.

The visual style blends **Minimalism** with **Tonal Ambient Diffusion**:
- **Ethereal Spatiality:** Generous negative space paired with warm, luminous parchment backgrounds that give complex multi-agent workflows breathing room.
- **Ambient Chromatic Glows:** Soft, diffused atmospheric auroras featuring saffron-gold, dawn-violet, and lavender hues that signify agent orchestration and deep thought without visual noise.
- **Micro-Precision Detail:** Hairline borders, monospaced computational tags, and crisp pill markers that reinforce mathematical rigor, sovereign trust, and enterprise reliability.

## Colors

The palette is engineered around high luminance contrast on a subtly warm, serene canvas. 

- **Primary (`#1E2033`):** Deep indigo-tinted obsidian used for authoritative typography, primary action buttons, and sovereign branding marks.
- **Secondary (`#E07A2C`):** Vibrant sovereign saffron, serving as an energetic accent for active agent execution, breakthrough research highlights, and warm glow halos.
- **Tertiary (`#7A70BA`):** Contemplative dawn lavender, introducing cognitive calmness, multi-agent mesh connections, and secondary aura gradients.
- **Neutral Canvas (`#FAFAF8` & `#F9F9FB`):** A serene off-white parchment foundation that eliminates clinical harshness and provides an eye-resting background for sustained analysis.
- **Specialized Agent Accents:** Distinct, muted functional tones (`agent-deep-research`, `agent-dev-studio`, and `agent-legal`) allow specialized agents to be identified instantly while maintaining systemic harmony.

## Typography

Typography establishes an editorial counterpoint between classic sovereign intelligence and modern computational precision.

- **Headlines (`Newsreader`):** High-contrast, literary serif headers deliver philosophical weight, trust, and human-first sovereign dignity. Use regular weights with generous line-heights for titles and section introductions.
- **Body (`Plus Jakarta Sans`):** Clean, balanced, and open grotesque styling ensures maximum readability across data-dense agent outputs, multi-document reviews, and parameter configuration screens.
- **Technical & Computational Badges (`Space Grotesk`):** Clean, geometric monospace-leaning lettering that anchors execution times, agent telemetry, latency tokens, and code manifests.

## Layout & Spacing

The layout is built upon an expansive 12-column fluid grid system bounded by maximum container widths (1280px for standard pages, 1440px for multi-agent canvases).

- **Vertical Cadence:** Sections are separated by sweeping vertical buffers (`space-2xl` to `space-3xl`) to instill an unhurried, serene state of focus.
- **Grid Adaptability:**
  - **Desktop (1024px+):** 12 columns with 24px (`1.5rem`) gutters and minimum 64px (`4rem`) outer margins. Multi-agent dashboards can dock specialized side-drawers (System Architect, Doc Intelligence) seamlessly.
  - **Tablet (768px - 1023px):** 8 columns with 20px gutters and 32px outer margins. Multi-agent matrices fold from 3 columns into 2-column configurations.
  - **Mobile (<768px):** 4 columns with 16px (`1rem`) gutters and 20px (`1.25rem`) outer safe margins. Agent cards transition to horizontal sliding carousels or singular full-width stacks.

## Elevation & Depth

Visual hierarchy does not rely on heavy drop-shadows or stark borders. Instead, depth is conveyed through **Atmospheric Radial Diffusion** and **Hairline Ghost Borders**:

- **Tonal Canvas Stacking:** Base layers use `#FAFAF8`, cards use pure `#FFFFFF`, and interactive sub-containers employ subtle neutral tints (`#F0F1F5`).
- **Hairline Outlines:** Pure single-pixel boundaries using `#E6E7EE` (or 8-10% primary tint) maintain crisp separation while keeping the interface weightless.
- **Ambient Chromatic Halos:** Active cards, agent nodes, or focused query bars cast extremely diffused, low-opacity color auras (`box-shadow: 0 20px 60px -15px rgba(224, 122, 44, 0.08), 0 10px 40px -10px rgba(165, 187, 252, 0.12)`).
- **Glass Overlays:** Modals and sticky headers utilize subtle backdrop blur filters (`backdrop-filter: blur(16px); background: rgba(250, 250, 248, 0.85)`).

## Shapes

The geometric framework balances approachable softness with modern product precision:

- Standard components (agent cards, research previews, text inputs) utilize `rounded-md` (8px / 0.5rem) to `rounded-lg` (16px / 1rem).
- Persistent search/prompt bars, state indicators, and interaction chips adopt full pill geometry (`rounded-full` / 9999px).
- Structural agent preview canvases employ `rounded-xl` (24px / 1.5rem) with continuous curvature to frame analytical models gently.

## Components

### Buttons & Interactive Triggers
- **Primary Sovereign Button:** Solid deep obsidian (`#1E2033`) fill with white body text, `0.5rem` border radius, subtle hover elevation, and a micro-scale shift (`scale: 1.015`).
- **Secondary Aurora Button:** Translucent off-white surface with hairline border (`#E6E7EE`), gentle saffron/lavender border transition on hover, and dark text.
- **Pill Action Trigger:** Full capsule shape with small icon prefix, used for initiating agent swarms or prompt presets.

### Agent Cards (Multi-Agent Suite)
- **Container:** Pure `#FFFFFF` background, 1px `#E6E7EE` border, 16px rounded corners, and generous 24px inner padding.
- **Header:** Features a top-aligned abstract agent emblem paired with subtle gradient glow tints matching the agent's function (e.g., warm gold for Fast Research, deep violet for Legal Review).
- **Metadata:** Space Grotesk labels displaying agent latency, token context, and operational readiness.

### Prompt & Agent Orchestration Input
- Floating, pill-contoured elevated bar (`#FFFFFF`) with a permanent subtle atmospheric shadow (`rgba(30, 32, 51, 0.04)`).
- Prefix tag selector that allows users to route queries to dedicated agents (Auto Mode, Dev Studio, Market Analyst).
- Hairline division between input text and execution controls.

### Status Badges & Pills
- Monospaced operational indicators (`Space Grotesk`) with 11px font size, uppercase letter-spacing, and low-saturation pastel backgrounds (e.g., `#EEF2FF` for active, `#FEF3C7` for reasoning).
- Encased in a soft pill shape with 6px vertical and 12px horizontal padding.

### Specialized Agent Drawers & Split Workspaces
- Dual-pane layout featuring an off-white reasoning workspace on the left and a live execution canvas on the right, separated by an ultra-thin vertical divider.
- Integrated ambient glow along the active agent panel edge indicating active generation and inference.
